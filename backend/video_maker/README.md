# 로기 쇼츠(Shorts) 메이커 🐿️🎬

매일 아침 경제 뉴스를 6개의 씬(인트로, 코인, 주식, 경제, 부동산, 아웃트로)으로 나누어, 다람쥐 '로기'의 목소리와 함께 유튜브 쇼츠(9:16) 영상을 자동으로 만들어주는 마법의 파이썬 스크립트입니다!

## 🚀 사용 방법

1. **파이썬 라이브러리 설치**
   터미널(명령 프롬프트)을 열고 아래 명령어를 입력하세요.
   ```bash
   pip install -r requirements.txt
   ```

2. **배경 이미지 교체 (선택 사항)**
   `assets/` 폴더 안에 있는 `coin_bg.png`, `stock_bg.png` 등의 이미지를 여러분이 원하는 멋진 배경 이미지로 교체하세요. (1080x1920 세로형 추천)
   *만약 이미지가 없으면 프로그램이 알아서 단색 배경을 임시로 만들어줍니다!*

3. **대본 수정**
   `main.py` 파일의 `SCENES` 배열 안에 있는 `text` 부분을 오늘 수집한 진짜 뉴스로 바꿔주세요.

4. **영상 제작 실행!**
   아래 명령어를 실행하면 `output/` 폴더에 `logi_shorts_오늘날짜.mp4` 파일이 뚝딱 완성됩니다!
   ```bash
   python main.py
   ```

## 🎙️ 캐릭터 및 목소리 설정
- `assets/logi_anchor.png`: 제가 예쁘게 그려드린 랩가운을 입은 연구원 로기 이미지입니다. 이 이미지가 영상 하단에 항상 등장합니다.
- 목소리는 `edge-tts`의 `ko-KR-SunHiNeural` (밝고 친근한 여성 목소리)를 사용했습니다. 아나운서처럼 딱딱하지 않고 로기와 아주 잘 어울립니다!
